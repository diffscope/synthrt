# Bundled G2P Resources

This repository no longer carries a G2P suite: this note is the only file under
`resources/G2pPackages/`. The restriction below applies to any build of
`Phonetic-Suite-Eng`, wherever it is prepared.

The redistribution provenance of that package is unverified: the source
revisions, transformation process, model checkpoint, training data and
redistribution licenses of its modified CMUdict data and ONNX model weights are
not recorded.

Do not include that package in release artifacts until all of those are
documented and reviewed.
